A for Coffee: the program writes exactly one letter, "A" for coffee, to /output/entry.txt — 1 UTF-8 character, inside the 1–1 gate — deterministically, with Python's standard library only. Coffee is the bolder, more vivid choice: the judge picks the letter whose choice of coffee or tea feels more vivid, funnier or truer, and coffee reads louder than tea.

## Run it

```sh
python3 main.py
```
